# Collections

A collection is a saved combination of the library view's own filters — status, tag,
score, format — under a name you give it, so you can jump straight back to "Dropped +
tagged 'revisit'" or "Planning + Action + unscored" without rebuilding the filter every
time.

## The important part: it's live, not a snapshot

A collection stores the **filter criteria**, never a list of specific anime ids.
Re-applying it always re-runs that filter against your library's *current* state. If
you add a new show tomorrow that matches a saved collection's criteria, it shows up
there automatically — you never need to go back and manually add it to anything.

This is the opposite of a "playlist"-style saved list, on purpose: a filter-based
collection can't go stale the way a fixed list of ids would the moment your library
changes underneath it.

## Managing collections

Collections are created and edited from the library view, wherever you'd normally set
filters — save the current filter combination as a named collection, and it appears
as a shortcut you can re-apply any time.
